# Quick Color Picker - Chrome Extension 🎨

> A lightweight, minimalist Chrome extension to sample hex colors directly from any live website and automatically build a saved palette.

---

### 👋 About The Creator
Hi, this is **DorkyDoffLok**!  
As someone working across 3D, animation, and digital visuals, grabbing accurate colors from screen references on the fly is a daily necessity. I created this lightweight extension to quickly pick colors, copy hex codes with one click, and store recent color swatches.

* 🐙 **GitHub:** [@DorkyDoffLok](https://github.com/DorkyDoff)

---

### ✨ Features
* **EyeDropper Integration:** Pick exact pixel colors from any webpage.
* **Auto-Clipboard:** Selected hex values copy instantly to your clipboard.
* **Palette History:** Stores your last 10 sampled colors in local browser storage.
* **Minimal Dark UI:** Clean, distraction-free pop-up interface.

---

### 🛠️ How to Install in Chrome
1. Download or clone this repository to your computer.
2. Open Google Chrome and type `chrome://extensions/` in the address bar.
3. Turn **ON** the **Developer mode** toggle located at the top-right corner.
4. Click the **Load unpacked** button in the top-left corner.
5. Select this project folder (`ColorPickerExtension`).
6. Pin the extension from your puzzle icon toolbar and start picking colors!
